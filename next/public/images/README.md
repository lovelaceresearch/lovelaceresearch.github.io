# Image Resources

This folder contains image assets for the Lovelace Research static site.

## Structure
- `contributors/` — Photos for the contributor hover cards
- `general/` — General imagery used across pages
- `logos/` — Partner and collaborator logos displayed on the logo wall
- `slides/` — Background imagery for the home page hero

## Guidelines
- Prefer WebP or optimized JPG for photos, SVG for line art & logos.
- Keep file sizes lean (generally <250 KB) to maintain fast load times.
- Reference assets from JSON using paths like `images/...` (no leading slash).
